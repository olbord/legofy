Projekti käivitamise juhend


1) git clone https://gitlab.cs.taltech.ee/nikest/veebilehe-projekt.git
2) install node.js from https://nodejs.org/en
3) run 'npm install sharp firebase-admin @google-cloud/storage express body-parser' in the project terminal
4) run backend/server.js
5) in a browser of your choice type in 'http://localhost:3000'

(doesn't work without FIREBASEkey.json and GCSkey.json (Google Cloud) in the backend/keys/)
